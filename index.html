Cara Kerja Penilaian

  1. Paket dicek dulu ke blacklist_ips → kalau IP ada di sana, langsung BLOCKED.
  2. Lalu dicek ke firewall_rules yang aktif → kalau cocok IP + port dengan aksi BLOCK, BLOCKED.
  3. Kalau tidak ada yang cocok, ALLOWED.
  4. Setiap keputusan dicatat ke security_logs (waktu, IP, port, jenis, tindakan).
Contoh IP jahat:
45.148.10.12 (blacklist)
185.220.101.47 (DDoS)
203.0.113.45 (aturan BLOCK)
